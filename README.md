## 🎯 ¿Qué hace?

| Métrica | Descripción |
|---------|-------------|
| **Toxicidad** | Detecta lenguaje ofensivo u hostil |
| **Viralidad** | Probabilidad de que el tweet se comparta |
| **Riesgo Ratio** | Probabilidad de recibir respuestas negativas |
| **Backlash** | Riesgo de ser "funado" |
| **Sarcasmo** | Detecta ironía y dobles sentidos |
| **Claridad** | Qué tan fácil de entender es |
| **Polarización** | Qué tan extremo es el mensaje |
| **Spam** | Detecta publicidad excesiva |
| **Clickbait** | Señal de cebo de clics |
| **Fake News** | Probabilidad de información falsa |

## ✨ Características adicionales

- 📊 **Gráfico Radar** - Visualiza las 6 métricas principales

- 📈 **Predicciones** - Likes estimados, RTs, mejor horario, hashtags sugeridos
